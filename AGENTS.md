# AGENTS.md — Linux Learning System

## Fast commands

```bash
# Start infrastructure (from project root)
docker compose -f docker/docker-compose.yml up -d

# Backend (Python 3.12, venv at backend/.venv)
# First-time: python3.12 -m venv backend/.venv && source backend/.venv/bin/activate && pip install -r backend/requirements.txt
cd backend && source .venv/bin/activate && uvicorn app.main:app --reload --port 8000
# Backend runs on :8000, health check at /health, API prefix /api/v1

# Frontend (Next.js 15 App Router)
cd frontend && npm run dev
# Frontend on :3000, proxies to :8000 in JS via fetch

# Build student Docker image (one-time)
bash scripts/build_student_image.sh
```

**Lint:** Frontend has `npm run lint` (next lint). Backend has ruff in `pyproject.toml` but no wired command — run `ruff check .` manually. No test commands exist yet.

**Entry points:** `backend/app/main.py` (FastAPI app), `frontend/app/layout.tsx` + `frontend/app/page.tsx`.

**Config authority:** `backend/app/config.py` defines ALL env settings with `LL_` prefix. `.env` lives at `backend/.env`, NOT project root.

**DB credentials:** user `lluser`, password `llpass`, database `ll_db` — hardcoded in docker-compose and .env.

## Source-of-truth docs

Specs live at `/root/docs/`, **not** `./docs/` within the project. Four Chinese markdown files by Dai Zelin and Lai Pengxu defining the full system. The project's `docs/` directory contains derived engineering artifacts (architecture, DB, OpenAPI) generated from those specs.

## Non-obvious constraints (from spec, must follow)

- **Terminal MUST use persistent bash session** — attach to a long-running `docker exec` process, never `docker exec` per command. State (cd, env, pwd) must persist.
- **Auth is JWT HttpOnly Cookie only** — `Set-Cookie: access_token=...; HttpOnly; SameSite=Lax; Path=/`. No localStorage. No query token in WS.
- **WebSocket auth via cookie** — `middleware/auth.py:ws_auth()` reads `access_token` cookie from WS handshake. Do NOT pass tokens in query params.
- **AI analysis must be async** — terminal output arrives first; AI analysis runs in parallel via the event bus. Blocking terminal for AI is a spec violation.
- **AI provider:** DeepSeek API at `https://api.deepseek.com`, model `deepseek-v4-pro`, temperature 0.3.
- **Student container:** Ubuntu 24.04, non-root `student` user with passwordless sudo, resource-limited (2GB mem, 1 CPU, 100 PIDs). Docker image at `linux-student:latest`.
- **Layout must be configurable** — `config/layout.config.ts` drives panel position/ratio. Never hardcode `left/right` in components.

## Phase 1 scope (what's IN)

M1 (done): skeleton + config + Docker Compose + PG/Redis + frontend/backend boot  
M2 (next): Auth module — register, login, logout, `/auth/me`

## Frontend patterns

- **Path alias:** `@/*` maps to `frontend/*` (see tsconfig.json)
- **API client:** `ApiClient` in `services/api.ts` uses `credentials: "include"` for cookie auth, always prepends `/api/v1` prefix
- **WS helper:** `config/api.config.ts` exports both `apiURL()` (http) and `wsURL()` (ws). Use `wsURL()` for WebSocket endpoints, NOT `apiURL().replace("http", "ws")`.
- **Stores:** Zustand v5, one file per domain (auth, terminal, ai, layout)
- **Route groups:** `(auth)/` for login/register, `(student)/` for playground/dashboard
- **Types:** `CommandAnalysis`, `User`, `ApiError`, `ConnectionStatus`, `TerminalSession` in `types/`
